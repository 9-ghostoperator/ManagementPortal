How to use this portal

  1. Open Properties to search or view college property records.
  2. Admin users can add, edit and delete property records.
  3. Use Requests to report maintenance problems or request a booking/allocation.
  4. Staff and Admin users can update the status of requests.
  5. Open Basic Reports to see property and request totals.
